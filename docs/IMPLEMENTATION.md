# Implementation Details

- **Language**: Python 3.12+ (tested on Python 3.13) & TypeScript
- **Frameworks**: FastAPI, Pydantic v2, DuckDB, Polars, scikit-learn, PyTorch, React 18, Vite, Tailwind CSS
- **Orchestration**: Constrained 6-role multi-agent crew with DeterministicSupervisor
- **Testing**: pytest, pytest-cov, Playwright
