# Public Repository Normalization

Ensures the public repository reads as an independent open-source engineering implementation and removes non-neutral project residue.

## Normalization Rules
1. Verify repository positioning is strictly an open-source defensive traffic analysis tool.
2. Remove employment-targeting, application framing, and non-neutral project residue from public files.
3. Ensure private build artifacts (`BUILD_SPEC.md`, `.build/`) remain uncommitted and git-ignored.
4. Verify all benchmark metrics in documentation are derived from reproducible evaluation runners.
