# Evidence Ledger

1. Every important public claim gets a claim ID in .
2. VERIFIED requires implementation + executed test/measurement.
3. Use PARTIAL, NOT_EXECUTED, REFERENCE_ONLY, or NOT_MEASURED when appropriate.
4. Docs-release agent may publish only claims with adequate evidence.
