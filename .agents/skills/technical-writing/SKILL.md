# Technical Writing

1. Write for skeptical engineers, not recruiters.
2. Prefer concrete file paths, commands, diagrams, results, and limitations.
3. Avoid inflated adjectives and vague claims.
4. Explain what, why, how, evidence, failure mode, and non-goals where relevant.
