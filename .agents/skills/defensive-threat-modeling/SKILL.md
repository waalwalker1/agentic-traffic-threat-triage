# Defensive Threat Modeling

1. Focus on observable behavior, identity evidence, intent hypotheses, and defensive response.
2. Synthetic fraud-like patterns must remain abstract/inert.
3. Include hard negatives and benign automation.
4. Never include bypass recipes, exploit instructions, or live target procedures.
